# ✈️ WanderLust – Modern Travel Accommodation Platform  
A clean, functional, and scalable **full-stack web application** inspired by platforms like Airbnb.  
WanderLust enables users to **discover, list, review, and book stays** with an intuitive UI and robust backend.

---

## 🌍 Project Overview

WanderLust is designed as a production-grade web app focusing on:

- **Property Listings** (create, update, delete)
- **User Authentication**
- **Image Uploads & Cloud Storage**
- **Review System**
- **Responsive UI**
- **RESTful APIs**
- **Secure Backend Architecture**

This repo serves as a complete learning + deployment-ready project for mastering backend web development and MERN-style full-stack workflows.

---

## 🏗️ Tech Stack

### **Frontend**
- HTML5, CSS3, JavaScript
- EJS templating
- Responsive layout with modern UI patterns

### **Backend**
- **Node.js**
- **Express.js**
- **MongoDB** with Mongoose ORM

- Image Storage (Cloud provider like Cloudinary)

- Git & GitHub
- VS Code

## ⚡ Core Functional Workflows

### 1. **Creating a Listing**
- User logs in  
- Fills form + uploads images  
- Server validates input  
- Images stored in cloud  
- Document saved in MongoDB  

### 2. **Reviewing a Listing**
- User adds rating + comment  
- Linked to listing & user  
- Average rating updated  

### 3. **Secure Authentication**
- Passport local strategy  
- Sessions + cookies  
- Route protection for CRUD operations
